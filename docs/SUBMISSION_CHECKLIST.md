# Submission Checklist

## Required by the rules
- [ ] Public GitHub repository (this repo), history inside the event window
- [ ] Demo video ≤ 3 min on YouTube (public/unlisted), opens in a signed-out browser
- [ ] Short writeup: problem, what we built, where AWS fits
- [ ] AWS usage visible **in the video**
- [ ] AI coding tools used listed in the writeup
- [ ] Third-party code, libraries and data credited with licences
- [ ] Every team member registered + AWS Builder Center student verification done
- [ ] Submitted on the event's own form before the deadline (one per team)

## Quality bar
- [ ] Deployed URL works on mobile
- [ ] Replay mode clearly labelled
- [ ] Data sources + freshness stated in app footer and README
- [ ] README has architecture diagram and setup steps
- [ ] No secrets in the repo (`.env` ignored; keys in SSM/Secrets Manager or Lambda env)

## Extras
- [ ] AWS Builder Center blog post (top 5 win AirPods), linked in submission
- [ ] Short LinkedIn/X post after submitting
